🧩 Pattern Catalog — 12 GoF-Level FL Patterns

P-01
FederatedMediator
GoF: Mediator
Aggregation server coordinates without clients knowing each other. Prevents tight coupling between FL participants.
GDPR ✓ HIPAA ✓ Risk: Low
P-02
DifferentialDecorator
GoF: Decorator
Wraps any gradient update with DP noise injection. Swappable ε values without touching training code.
GDPR Art.25 ✓ HIPAA ✓ Risk: Low
P-03
FederatedStrategy
GoF: Strategy
FedAvg / FedProx / FedNova swappable behind common interface. Algorithm choice decoupled from client training.
GDPR ✓ HIPAA ✓ Risk: Low
P-04
SecureAggregationProxy
GoF: Proxy
Intercepts weight transmission, applies homomorphic encryption transparently before forwarding to server.
GDPR Art.32 ✓ HIPAA ✓ Risk: Low
P-05
ConsentObserver
GoF: Observer
Client notifies server when patient consent policy changes. Server evicts client from current round automatically.
GDPR Art.7 ✓ HIPAA ⚠ Risk: Medium
P-06
StragglerCircuitBreaker
GoF: Chain of Responsibility
Drops clients exceeding timeout threshold without blocking the FL round. Partial quorum continues training.
GDPR ✓ HIPAA ✓ Risk: Low
P-07
VersionedModelPrototype
GoF: Prototype + Memento
Clones global model at each round. Restores last clean checkpoint when poisoning attack detected by validation.
GDPR ⚠ HIPAA ✓ Risk: Medium
P-08
RoundCommandHistory
GoF: Command
Each FL round encapsulated as a reversible Command object. Enables regulatory audit trail replay for HIPAA compliance.
GDPR ⚠ Risk HIPAA ✓ Risk: High
P-09
DataPartitionBuilder
GoF: Builder
Constructs IID or Non-IID data splits step-by-step. Dirichlet α controls heterogeneity per simulated hospital.
GDPR Art.25 ✓ HIPAA ✓ Risk: Low
P-10
HeterogeneityAdapterFactory
GoF: Abstract Factory
Creates appropriate client adapters for edge / cloud / GPU / CPU hardware without changing core FL logic.
GDPR ✓ HIPAA ✓ Risk: Low
P-11
FedModelSingleton
GoF: Singleton
Ensures exactly one global model instance exists per round on the server. Prevents race conditions during aggregation.
GDPR ✓ HIPAA ✓ Risk: Low
P-12
GradientIterator
GoF: Iterator
Traverses client gradient updates sequentially without exposing internal gradient collection structure to aggregator.
GDPR ✓ HIPAA ✓ Risk: Low
